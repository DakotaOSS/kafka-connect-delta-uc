# Security policy

## Supported versions

Pre-1.0 (0.1.x) and dependent on a Databricks Beta preview — treat it as experimental. Security fixes
land on the latest 0.1.x.

| Version | Supported |
|---|---|
| 0.1.x | yes |
| < 0.1 | no |

## Reporting a vulnerability

Do not open a public issue for security problems. Email **jordan@dakotaanalytics.com** with details and
repro steps. Expect an acknowledgement within a few business days; we'll coordinate a fix and disclosure
from there.

When reporting, redact any tokens, SAS, or storage paths from logs and stack traces.
